# SpeedTask

**習慣は、スワイプで終わらせる。**

今日の習慣がカードの束になって出てきます。右にスワイプで「やった！」、左にスワイプで「パス（あとでもう一回）」。
最初のスワイプから全部終わるまでの秒数を計って、「6秒で、今日が終わった。」を目指すアプリです。

## できること

- **ホーム**：カードを右スワイプで完了、左スワイプで後ろに回す。残り枚数・連続日数・経過秒数を表示。左上の矢印で「ひとつ戻す」
- **ALL DONE!**：全部終わると連続日数、直近7日、かかった秒数を表示
- **カレンダー**：全部できた日／一部できた日を月ごとに表示。日付をタップでその日の内容
- **記録**：日ごとの達成度とタイム（ベストタイムに印）
- **分析**：いまの連続・最長の連続・全部できた率・ベストタイム、直近14日のグラフ、習慣ごとの達成率
- **設定**：習慣の追加・名前変更・色・並べ替え・削除、データのリセット

キーボード：`→` やった / `←` パス / `Z` ひとつ戻す

## 使い方

ビルド不要の静的サイトです。

```sh
npx http-server -p 8080 .
# → http://localhost:8080 を開く
```

GitHub Pages などにそのまま置けます。スマホでは「ホーム画面に追加」でアプリのように使え、オフラインでも動きます（`manifest.webmanifest` と `sw.js`）。

記録はブラウザの `localStorage` にだけ保存されます。初回はサンプルの記録が入っているので、設定かバナーの「サンプルを消す」で消してください。

| ファイル | 中身 |
