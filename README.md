# SpeedTask

**習慣は、スワイプで終わらせる。**

今日の習慣がカードの束で出てきます。右にスワイプで「やった」、左にスワイプで「できなかった」。
全部スワイプし終えたら、今日の達成率が出ます。

## 画面

**はじめに**（初回だけ）
- 候補をタップするか自分で書いて、毎日の習慣を選んで始めます。「サンプルの記録で試してみる」で記録入りのデモも見られます

**ホーム**（アプリを開くとここ）
- 今日のカード：「今日の習慣 5枚 → スワイプではじめる」。途中なら「あと3枚 → つづける」、終わったら達成率（例：80%・5つ中4つ）。できなかった分があれば「やり直す」
- 今日の習慣の一覧：やった／できなかった／まだ。今日の分はタップで直せます
- この7日のドットと連続日数、「記録をすべて見る」
- 右上の歯車から習慣の編集へ

**スワイプ**（ホームのカードから）
- 右へ＝やった、左へ＝できなかった。スワイプ直後だけ下に「取り消す」が出ます
- 上に残り枚数と連続日数。左上の × でホームへ
- 全部スワイプし終えると、達成率・直近7日・連続日数を表示
- その日にやる習慣がない日は「今日はお休み。」

**記録**
- 連続日数・30日の達成率・ベストタイム
- 月のカレンダー（濃い緑＝全部できた、薄い緑＝一部できた）と、日付ごとの中身
- 習慣ごとの連続日数と30日の達成率
- **過去の記録は見るだけで、変えられません**

**習慣**（ホームの歯車から）
- 追加・名前変更・色・並べ替え・削除
- 曜日の指定（毎日／平日／土日／好きな曜日）
- バックアップの書き出しと読み込み、記録の消去

### 過去の記録は変わらない
- 曜日の変更は、変えた日から先にだけ効きます。過去の日は当時の曜日のまま
- 習慣は追加した日から数えます。あとから足した習慣が、前の日の「できなかった」になることはありません
- 削除した習慣は今日から消えますが、過去の日の記録には残ります

### 数え方
- **達成率**：できた数 ÷ その日にやる予定だった数。今日の分は全部スワイプし終えてから数えます
- **連続日数**：最後までスワイプした日が続いた日数。できなかった習慣があっても途切れません。やる習慣がない日（お休み）は飛ばします
- **秒数**：スワイプしていた時間だけ。前のスワイプから60秒以上あいた分は数えません
- **ベストタイム**：全部できた日のタイムだけで比べます

キーボード：`→` やった / `←` できなかった / `Z` 取り消す

## 使い方

ビルド不要の静的サイトです。

```sh
npm start            # http://localhost:8080
```

GitHub Pages などにそのまま置けます。スマホでは「ホーム画面に追加」でアプリとして使え、オフラインでも動きます。
記録はブラウザの `localStorage` にだけ保存されます。機種変更の前は「バックアップを書き出す」で保存してください。

## テスト

```sh
npm install
npm test
```

`tests/e2e.cjs` がリポジトリを小さなサーバーで配信し、スマホサイズの Chromium（Playwright）でアプリを操作して確かめます。
