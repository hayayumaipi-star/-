# SpeedTask

**習慣は、スワイプで終わらせる。**

今日の習慣がカードの束で出てきます。右にスワイプで「やった」、左にスワイプで「できなかった」。
最初のスワイプから最後の1枚までの秒数を計って、「6秒で、今日が終わった。」を目指します。

## 画面は2つだけ

**今日**
- カードを右へ＝やった、左へ＝できなかった。スワイプ直後だけ下に「取り消す」が出ます
- 上に残り枚数と連続日数、真ん中に計測中の秒数
- 全部スワイプし終えると、今日の達成率（例：80%・5つ中4つ）・直近7日・連続日数を表示。タイムは1時間以内に片付けた日だけ小さく添えます。できなかった分は「やり直す」で後から片付けられます（タイムは最初の記録のまま）

**記録**（左上のカレンダーから）
- 連続日数・30日の達成率・ベストタイム
- 月のカレンダー（濃い緑＝全部できた、薄い緑＝一部できた）。日付をタップすると、その日の記録をタップで直せます（つけ忘れ・押し間違い）
- 習慣ごとの連続日数と30日の達成率
- 「編集」から習慣の追加・名前変更・色・並べ替え・削除

### 数え方
- **連続日数**：最後までスワイプした日が続いた日数。できなかった習慣があっても途切れません
- **達成率**：できた回数 ÷ 習慣の数
- **ベストタイム**：全部できた日のタイムだけで比べます

キーボード：`→` やった / `←` できなかった / `Z` 取り消す

## 使い方

ビルド不要の静的サイトです。

```sh
npx http-server -p 8080 .
# → http://localhost:8080 を開く
```

GitHub Pages などにそのまま置けます。スマホでは「ホーム画面に追加」でアプリとして使え、オフラインでも動きます。

記録はブラウザの `localStorage` にだけ保存されます。初回はサンプルの記録が入っているので、記録画面の「サンプルを消す」で消してください。
