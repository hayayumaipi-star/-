# SpeedTask

**習慣は、スワイプで終わらせる。**

今日の習慣がカードの束で出てきます。右にスワイプで「やった」、左にスワイプで「できなかった」。
全部スワイプし終えたら、今日の達成率が出ます。

## 画面

**はじめに**（初回だけ）
- 候補をタップするか自分で書いて、毎日の習慣を選んで始めます。「サンプルの記録で試してみる」で記録入りのデモも見られます

**今日**
- カードを右へ＝やった、左へ＝できなかった。スワイプ直後だけ下に「取り消す」が出ます
- 上に残り枚数と連続日数、真ん中にスワイプにかかった秒数
- 全部スワイプし終えると、達成率（例：80%・5つ中4つ）・直近7日・連続日数を表示。「シェア」で結果を画像とテキストで共有、「やり直す」でできなかった分を後から片付けられます
- その日にやる習慣がない日は「今日はお休み。」

**記録**（左上のカレンダーから）
- 連続日数・30日の達成率・ベストタイム
- 月のカレンダー（濃い緑＝全部できた、薄い緑＝一部できた）。日付をタップすると、その日の記録をタップで直せます（つけ忘れ・押し間違い）
- 習慣ごとの連続日数と30日の達成率

**習慣**（記録の「編集」から）
- 追加・名前変更・色・並べ替え・削除
- 曜日の指定（毎日／平日／土日／好きな曜日）
- バックアップの書き出しと読み込み、記録の消去

### 数え方
- **達成率**：できた数 ÷ その日にやる予定だった数。今日の分は全部スワイプし終えてから数えます
- **連続日数**：最後までスワイプした日が続いた日数。できなかった習慣があっても途切れません。やる習慣がない日（お休み）は飛ばします
- **秒数**：スワイプしていた時間だけ。前のスワイプから60秒以上あいた分は数えません
- **ベストタイム**：全部できた日のタイムだけで比べます

キーボード：`→` やった / `←` できなかった / `Z` 取り消す

## 使い方

ビルド不要の静的サイトです。

```sh
npm start            # http://localhost:8080
```

GitHub Pages などにそのまま置けます。スマホでは「ホーム画面に追加」でアプリとして使え、オフラインでも動きます。
記録はブラウザの `localStorage` にだけ保存されます。機種変更の前は「バックアップを書き出す」で保存してください。

## テスト

```sh
npm install
npm test
```

`tests/e2e.cjs` がリポジトリを小さなサーバーで配信し、スマホサイズの Chromium（Playwright）でアプリを操作して確かめます。
