# Google Play に公開する手順

スマホだけで進められるように書いています。上から順に進めてください。

## 全体の流れと日数

| 段階 | やること | かかる時間 |
| --- | --- | --- |
| 1 | Play Console のデベロッパー登録 | 登録は数十分、本人確認に数日 |
| 2 | GitHub にパスワードを1つ登録して、提出用ファイル（AAB）を作る | 10分 |
| 3 | Play Console でアプリを作り、掲載情報を入れる | 1時間ほど |
| 4 | クローズドテスト（12人以上で14日間） | **14日以上** |
| 5 | 製品版の公開を申請 → 審査 | 数日 |

**注意：** 2023年11月以降に作った個人のデベロッパー アカウントは、製品版を出す前に「12人以上のテスターが14日間続けて参加するクローズドテスト」が必要です。テスターになってくれる人を先に集めておくと早く進みます。

---

## 1. デベロッパー登録

1. https://play.google.com/console を開き、使う Google アカウントでログイン
2. アカウントの種類は「**個人**」を選ぶ
3. 登録料 **25ドル**（1回だけ）を支払う
4. 本人確認（身分証の写真）と電話番号の確認をする
5. 「Play Console」アプリで Android 端末の確認をする（求められた場合）

本人確認が終わるまで数日かかることがあります。その間に 2 と 3 を進められます。

## 2. 提出用ファイル（AAB）を作る

アプリへの署名に使う鍵は、暗号化してリポジトリに入れてあります（`android/upload-keystore.jks.enc`）。開くためのパスワードを GitHub に登録すると、提出用ファイルが自動で作られます。

1. GitHub でこのリポジトリを開く
2. **Settings → Secrets and variables → Actions → New repository secret**
3. Name に `ANDROID_KEYSTORE_PASSWORD`、Secret に **Claude から受け取ったパスワード** を入れて保存
4. **Actions → Android → Run workflow** を押す（以後はプッシュのたびに自動で作られます）
5. 終わったら、その実行の画面の下にある **Artifacts** から
   - `swipe-habit-play-aab-番号` … Play に提出するファイル（zip の中の `app-release.aab`）
   - `swipe-habit-test-apk-番号` … 手元のスマホで試すためのファイル（zip の中の `app-debug.apk`）

   をダウンロードします。

**パスワードは必ずパスワード管理アプリなどに保管してください。** なくすと、今後のアップデートを作れなくなります（その場合は Play Console から「アップロード鍵のリセット」を申請できますが、数日かかります）。

### 手元で試す
`app-debug.apk` をスマホで開くとインストールできます（「提供元不明のアプリ」を許可するよう求められます）。

## 3. Play Console でアプリを作る

1. Play Console → **アプリを作成**
   - アプリ名：`スワイプ習慣`
   - デフォルトの言語：日本語
   - アプリ／ゲーム：アプリ
   - 無料／有料：無料
2. 左のメニューの **ダッシュボード** に「アプリのセットアップ」の一覧が出るので、上から埋めます。答えはすべて [store/listing-ja.md](../store/listing-ja.md) にまとめてあります。
   - **プライバシー ポリシー**：次の URL を入れる
     `https://github.com/hayayumaipi-star/-/blob/claude/a-jw1q6l/docs/privacy.md`
   - **アプリのアクセス権**：すべての機能が制限なしで使える
   - **広告**：含まない
   - **コンテンツのレーティング**：アンケートに答える（すべて「いいえ」）
   - **ターゲット層**：18歳以上
   - **データ セーフティ**：データを収集・共有しない
   - **政府／金融／健康アプリ**：いずれも該当しない
3. **メインのストアの掲載情報**
   - 簡単な説明・詳しい説明：listing-ja.md から貼り付け
   - アプリアイコン：`store/icon-512.png`
   - フィーチャー グラフィック：`store/feature-graphic.png`
   - スマートフォンのスクリーンショット：`store/screenshots/` の 5 枚

画像は GitHub でファイルを開き、「Download raw file」でスマホに保存できます。

## 4. クローズドテスト

1. **テスト → クローズド テスト → トラックを作成**（名前は「テスト」など）
2. **テスターを追加**：テスターの Gmail アドレスをメーリングリストとして登録（12人以上）
3. **新しいリリースを作成**
   - 「Play アプリ署名」は Google に任せる（初期設定のまま）
   - `app-release.aab` をアップロード
   - リリース名は自動のままでよい。リリースノートに「最初のテスト版です」など
4. **審査に送信**。通ると、テスター用の参加リンクが表示されるので、テスターに送る
5. テスターがリンクから参加し、アプリを入れたまま **14日間** 過ごす

## 5. 製品版を公開する

1. 14日たつと、ダッシュボードに「**製品版へのアクセスを申請**」が出る。テストの内容についての質問に答えて申請
2. 承認されたら **製品版 → 新しいリリースを作成** で同じ AAB（または新しい AAB）をアップロードして **審査に送信**
3. 審査が通ると Google Play に公開されます

## アップデートのしかた

1. アプリを直してプッシュする
2. Actions が新しい `app-release.aab` を作る（番号は自動で増えます）
3. Play Console の製品版（またはテスト）で新しいリリースを作り、アップロード

## 変えられないもの・変えられるもの

- **パッケージ名 `jp.swipeshukan.app` は、一度公開すると変えられません。** 変えたい場合は最初のアップロードの前に `capacitor.config.json` と `android/app/build.gradle` を直します
- アプリ名・説明・画像はいつでも変えられます
- アイコンを変えたら `npm run icons`、画面を変えたら `npm run screenshots` で画像を作り直せます
